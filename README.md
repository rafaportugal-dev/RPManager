# 📖 Sobre

O **RPManager ERP** é um sistema desktop desenvolvido em **Python** com interface gráfica em **PySide6**, criado para gerenciamento de:

- Assistências Técnicas
- Lojas
- Comércio
- Pequenas Empresas

O projeto está sendo desenvolvido durante minha graduação em **Análise e Desenvolvimento de Sistemas**, aplicando boas práticas de desenvolvimento, arquitetura de software e organização de projetos.

O objetivo é construir um ERP moderno, escalável e profissional.

# 🚀 Instalação

Clone o projeto

```bash
git clone https://github.com/rafaportugal-dev/RPManager.git
```

Entre na pasta

```bash
cd RPManager
```

Instale as dependências

```bash
pip install -r requirements.txt
```

Execute

```bash
python main.py
```
