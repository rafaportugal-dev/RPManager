# 📖 Sobre

O **RPManager** é um sistema desktop desenvolvido em **Python** para auxiliar assistências técnicas e lojas no gerenciamento completo de clientes, produtos, estoque, ordens de serviço e financeiro.

O projeto está sendo desenvolvido como parte do meu portfólio durante a graduação em **Análise e Desenvolvimento de Sistemas** na **Cruzeiro do Sul Virtual**, aplicando conceitos de programação, banco de dados, interface gráfica e arquitetura de software.

# 🚀 Instalação

Clone o repositório

```bash
git clone https://github.com/rafaportugal-dev/RPManager.git
```

Entre na pasta

```bash
cd RPManager
```

Instale as dependências

```bash
pip install -r requirements.txt
```

Execute

```bash
python main.py
```
