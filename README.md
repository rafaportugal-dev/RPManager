## 📖 Sobre o Projeto

O **RPManager** é um sistema desktop desenvolvido para auxiliar assistências técnicas e lojas no gerenciamento de clientes, ordens de serviço, estoque, vendas e financeiro.

Este projeto está sendo desenvolvido como parte do meu aprendizado no curso de **Análise e Desenvolvimento de Sistemas** da **Cruzeiro do Sul Virtual**, servindo como portfólio prático para minha carreira na área de tecnologia.

## 🚀 Como executar

Clone o projeto:

```bash
git clone https://github.com/rafaportugal-dev/RPManager.git
```

Entre na pasta:

```bash
cd RPManager
```

Instale as dependências:

```bash
pip install -r requirements.txt
```

Execute:

```bash
python main.py
```
